# Quantum - Stock Trading Platform

**Stocks. Made accessible!**

Quantum is a modern, full-featured stock trading SaaS platform built with SvelteKit. It provides an intuitive interface for tracking stocks, analyzing market data, and managing investment portfolios.

## 🚀 Features

### Core Functionality

- **Interactive Stock Charts** - Real-time candlestick charts with multiple timeframe options (1d, 5d, 2w, 1m, 6m, 1y, 5y, max)
- **Market Data Dashboard** - Live stock prices, pre-market data, and comprehensive market statistics
- **Portfolio Management** - Track your holdings, view performance metrics, and monitor gains/losses
- **Watchlist** - Keep track of your favorite stocks with customizable watchlists
- **Analytics** - Detailed sector allocation, performance tracking, and investment insights
- **Market News** - Stay updated with the latest financial news and market developments

### User Experience

- **Modern UI/UX** - Clean, professional interface with smooth animations and transitions
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode Support** - Stock charts with dark theme for comfortable viewing
- **Real-time Updates** - Live price updates and market data

### Trading Features

- **Buy/Sell Interface** - Quick access to trading actions with current bid/ask prices
- **Stock Details** - Comprehensive financial metrics including PE ratio, EPS, market cap, and more
- **Historical Data** - Access to historical performance and trends
- **Performance Metrics** - Day's range, 52-week range, volume, and average volume

## 🛠️ Tech Stack

- **Framework**: SvelteKit 2.0
- **Styling**: Tailwind CSS 4.0
- **UI Components**: Svelte-UX
- **Language**: TypeScript
- **Testing**: Vitest + Testing Library
- **Build Tool**: Vite 6.0

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run tests
npm test

# Lint code
npm run lint

# Format code
npm run format
```
